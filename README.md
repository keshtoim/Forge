Forge записывает тренировки в зале: какие упражнения, сколько подходов, какой вес и насколько было тяжело. Всё хранится на телефоне. Аккаунта, рекламы и подписки нет. В интернет приложение выходит только ради ИИ-помощника, если ты его включишь, и раз в день проверить обновления на GitHub (это отключается). Данные тренировок никуда не уходят без твоего вопроса ИИ.

## Как проходит тренировка

1. **Выбираешь шаблон** или начинаешь пустую тренировку и добавляешь упражнения из каталога.
2. **Записываешь подход.** Вес и повторы прошлой тренировки уже подставлены серым, остаётся поправить цифры и нажать «Готово». Для штанги можно вводить блины на сторону: гриф Forge прибавит сам и подскажет, что вешать («вешай: 25 + 15 + 1.25»). На пустом подходе видна цель по двойной прогрессии, например «102.5 кг × 7», её можно подставить одним нажатием.
3. **Отмечаешь, насколько было тяжело.** Пять уровней с цветами, расшифровка по кнопке «?».
4. **Отдыхаешь.** Таймер отдыха висит в уведомлении и вибрирует, когда пора, даже при выключенном экране. Отдых свой для каждого упражнения: по умолчанию 3 минуты для базовых и полторы для изолирующих.

Если закрыть приложение посреди тренировки, она продолжится с того же места.

**Разминка и заметки.** Кнопка «Разминка» добавляет перед рабочими подходами 40, 60 и 80 % рабочего веса. К упражнению можно оставить заметку («сиденье на 4»), она видна на каждой следующей тренировке, а к тренировке — свою («плохо спал»).

**Суперсеты.** Соседние упражнения в шаблоне можно объединить в суперсет. Тогда на экране тренировки весь круг виден сразу, «Круг готов» отмечает все упражнения, а отдых начинается только после круга. «Ещё один круг» добавляет круг с теми же весами.

### Уровни подхода

| | Уровень | Когда ставить |
|---|---|---|
| ⚪ | Разминка | Не идёт в рекорды и статистику |
| 🟢 | Лёгкий | Большой запас повторов |
| 🟡 | Средний | Рабочий подход, в запасе 3–4 повтора |
| 🟠 | Тяжёлый | В запасе 1–2 повтора |
| 🔴 | Максимум | До отказа или рекордный вес |

## Что ещё внутри

**Каталог упражнений.** 116 встроенных упражнений во всех группах мышц и свои. У каждого есть карта мышц (мужская или женская фигура), техника, частые ошибки и характеристики: тип, вид, оборудование, тип усилия. Каталог фильтруется по любой их комбинации.

**Прогресс.** Графики по каждому упражнению (вес, объём, повторы, время, дистанция), личные рекорды, статистика за 30 дней и карта нагрузки на мышцы на главном экране.

**Планы.** Тренировку можно поставить на дату: по шаблону или со своим списком упражнений. Она появится в календаре, на главной и в «Предстоящих», а в нужный день придёт напоминание.

**Замеры тела.** Вес и обхваты по дням с графиком динамики. По ним Forge считает ИМТ, процент жира по методу ВМС США, сухую массу, FFMI и отношение талии к росту и бёдрам.

**Твои данные.** Всё выгружается в JSON и загружается обратно, например при переезде на новый телефон.

## ИИ-помощник (по желанию)

По умолчанию выключен, и без него Forge работает как обычно. Чтобы включить, нужен свой API-ключ одного из сервисов: Gemini (Google AI Studio), ChatGPT (OpenAI) или Claude (Anthropic). После ввода ключа Forge сам загрузит список доступных моделей, и останется выбрать модель. «Проверить подключение» просит модель ответить и показывает понятную причину, если что-то не так: ключ, регион, баланс или модель.

- **Чат-тренер.** Метка «ИИ» в шапке тренировки открывает чат. Тренер видит текущую тренировку, прошлые результаты, заметки и данные тела (фигура, рост, возраст, вес с динамикой и состав тела), поэтому отвечает по делу: какой вес взять, сколько отдыхать, чем заменить занятый тренажёр. К вопросу можно приложить до трёх фото из галереи или с камеры.
- **Совет по подходу.** Кнопка «Совет ИИ» в карточке подхода предлагает вес и повторы с коротким объяснением, «Применить» подставляет их в подход.
- **Разбор тренировки.** После тренировки кнопка «Разобрать тренировку» даёт три-четыре строки: что выросло, что просело и на что смотреть в следующий раз.
- **Программа от ИИ.** В «Справочники → Шаблоны» анкета (цель, дни, время, уровень, оборудование, ограничения), и ИИ собирает программу из упражнений справочника. Её можно посмотреть и сохранить шаблонами вместе с суперсетами.
- **Индикатор связи.** Точка на метке «ИИ»: зелёная — на связи, серая — проверка, красная — нет интернета или ключ не подошёл.

Данные тренировки уходят только выбранному сервису и только когда ты спрашиваешь. В экспорт данных ключ не попадает. Ключ хранится на устройстве, зашифрованный ключом из Android Keystore.

## Установка

Готовый APK лежит в [релизах](https://github.com/keshtoim/Forge/releases). Нужен Android 8.0 или новее.

Дальше приложение обновляется само: в «Ещё» появится «Доступна версия X», Forge скачает APK, сверит его контрольную сумму и подпись и откроет системную установку поверх текущей версии, данные сохраняются. Обновляется только сборка из релиза: отладочный APK из Actions подписан другим ключом.

Собрать самому:

```bash
git clone https://github.com/keshtoim/Forge.git
cd Forge
./gradlew assembleDebug      # app/build/outputs/apk/debug/
./gradlew testDebugUnitTest  # тесты
```

Понадобятся JDK 17+ и Android SDK 36.

## Для разработчиков

Kotlin, Jetpack Compose с Material 3, Room, Navigation Compose с типобезопасными маршрутами и kotlinx.serialization. ИИ-помощник работает через официальные SDK: google-genai, openai-java и anthropic-java. DI-фреймворка нет: экран → ViewModel → DAO.

```
data/        Room, встроенные упражнения, формулы тела, настройки
rest/        таймер отдыха (foreground service)
data/ai/     ИИ-помощник: SDK провайдеров, настройки, промпт тренера
reminder/    напоминания о планах (AlarmManager)
ui/          экраны по разделам: workout, history, exercises, plan, …
```

Пара решений, которые стоит знать:

- **Встроенные упражнения описаны в коде**, в базе хранится только их ключ. Мышцы, техника и характеристики обновляются вместе с приложением, без миграций.
- **Схема базы версионируется**, миграции проверяются тестами на экспортированных схемах из `app/schemas`.
- **Версия берётся из тега.** На push тега `vX.Y.Z` GitHub Actions собирает подписанный APK и публикует релиз с той же версией.

Тесты гоняются на Robolectric, включая UI-сценарии на Compose, так что эмулятор для них не нужен.

## Разрешения

- **Уведомления** — таймер отдыха и напоминания о тренировках.
- **Foreground service** — таймер продолжает идти, пока приложение свёрнуто.
- **Точные будильники и автозапуск** — напоминание приходит вовремя, в том числе после перезагрузки.
- **Вибрация и wake lock** — сигнал о конце отдыха при выключенном экране.
- **Интернет и состояние сети** — ИИ-помощник, его индикатор связи и проверка обновлений.
- **Установка приложений** — открыть системную установку скачанного обновления; Android спросит разрешение один раз.
